# Usage de l'IA dans le projet

**Problème**
La problématique de base de ce projet est *Comment apprendre la syntaxe pour pouvoir se reposer sur l'IA dans le futur de ma carrière pro*

---

## 2026/09/17

**Ce que je cherchais**


**Production de l'IA**
Dans cette problématique, j'ai prompté spécifiquement l'IA pour lui interdire de me sortir de code déjà fait, ou une architecture déjà décidée par elle-même. Ses réponses sont à titre indicatif et me permettent d'apprendre la syntaxe comme on pourrait suivre une doc d'un cours ou d'une documentation officielle. Elle me pose des questions auxquelles je dois répondre et trancher pour avancer. Si je me plante complètement elle hésite pas à me le dire. J'ai orienté au fil du projet le prompt pour qu'elle me donne des exemples afin de mieux saisir comment écrire l'architecture. De plus ça me permet d'apprendre le vocabulaire de manière pointilleuse car elle me reprend pour tout abus de langage dans la conversation.

**Ma décision**
Mes décisions au cours du projet jusqu'alors se sont faites autour de l'architecture, de comment on allait vérifier une opération, des invariants qu'il fallait respecter, des choses à n'absolument pas autoriser comme la suppression d'un mouvement, de comment organiser le code et bien le documenter pour éviter des soucis de compréhension à la relecture.
